# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

The `maily` team takes the security of our software and users seriously. If you believe you have found a security vulnerability, please report it responsibly.

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred):**
   Submit a confidential advisory directly via GitHub:
   [Report a Vulnerability](https://github.com/stormsia/maily/security/advisories/new)

2. **Email:**
   Send an encrypted or private email to `sf_root@outlook.com` with the subject:
   `[SECURITY] Vulnerability in maily - <Brief Summary>`.

### What to Include

Please provide:
- A clear description of the vulnerability and affected components.
- Step-by-step instructions or a minimal proof-of-concept (PoC) to reproduce the issue.
- The potential impact and attack vectors.
- Any suggested remediations or patches if available.

### Our Commitment

- We will acknowledge receipt of your report within 48 hours.
- We will keep you updated on progress towards resolving the issue.
- Once fixed, we will publish a release and credit your responsible disclosure (unless you prefer anonymity).

Please **do not** open public GitHub issues or discussions for undisclosed security vulnerabilities.
